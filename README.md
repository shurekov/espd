# ЕСПД Контроль

Локальное приложение для ограниченной проверки DOCX-документов по выбранным профилям ЕСПД.

Приложение использует локальный OpenAI-совместимый LLM endpoint и независимый программный контроль части правил. Результат проверки не является заключением о полном соответствии документа ГОСТ или ЕСПД.

## Поддерживаемые профили

- **VED** — ведомость эксплуатационных документов, ГОСТ 19.507-79.
- **RSP** — руководство системного программиста, ГОСТ 19.503-79.
- **ROP** — руководство оператора, ГОСТ 19.505-79.
- **OPR** — описание программы, ГОСТ 19.402-78.

Состав проверок ограничен правилами из JSON-файлов соответствующих профилей.

## Требования

- Python 3.12+
- Node.js 22+
- npm
- Запущенный OpenAI-совместимый сервер модели с поддержкой `chat/completions` и JSON Schema
